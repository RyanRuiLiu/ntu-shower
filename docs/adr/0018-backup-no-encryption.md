# ADR-0018: 数据库备份暂不加密

- 状态：Accepted
- 日期：2026-11-06
- 决策者：项目负责人
- 取代：无

## 背景

`STANDARDS.md` §12.4.2 要求备份必须加密且密钥与备份分开保管。2026-11-05 审计按该条实现了 age 加密方案（公钥在服务器、私钥异地持有）。项目负责人于 2026-11-06 决定暂不加密：备份目录权限 700、服务器仅 SSH 密钥访问、单人运维即信任边界，引入 age 密钥的生成、托管与恢复流程对当前场景是净增负担（私钥丢失等于备份永久不可读）。

## 决策

备份维持明文 gzip：`VACUUM INTO` 在线备份 + 完整性校验 + 滚动保留 14 份，落在 `/var/backups/ntu-shower/`（700，root）。加密相关的脚本与文档改动已从分支移除。

## 备选方案

- 维持 age 加密：未选择——密钥托管与演练流程的成本高于单人运维下的收益。
- 应用层字段加密（审计表与凭证名单）：改动面大，列为后续可选项。

## 后果

- 正面：备份与恢复链路简单，恢复演练已验证（2026-09-30）；无密钥管理负担。
- 负面：备份文件泄露即可读（内含学号、浴室凭证与审计原文）；与 §12.4.2 的目标状态存在经记录的偏离（例外见 `CONTRIBUTING.md`）。
- 需要监控的风险：出现第二名运维者、备份需要离开本机（异地副本）、服务器目录权限变化——任一发生即重启加密决策。

## 验证

`ls -ld /var/backups/ntu-shower` 为 700/root；本例外按 `CONTRIBUTING.md` 的例外规则不是永久豁免，复核条件即上列三条风险。
