# 术语表

本文件是术语的唯一正名与弃用词。代码、文档、界面文案与提交信息使用这里的词。

## 正名

| 概念 | 正名 |
|---|---|
| 那台机器 | 设备 |
| 机器上我们装的程序 | NTU Shower |
| 浴室那套 App | 浴室 App |
| 出水的那个口 | 喷头 |
| 一次占用 | 会话（`usage_session`） |
| 一次连续出水 | 段（`usage_segment`） |
| 占用的人 | 学号（`cert_no`） |
| 喷头被分配给这个人的时刻 | 分配时刻（`assigned_at`） |
| 拿不到设备原文时退回的观测值 | 首次观测时刻（`assigned_source = observed`） |
| 这一段开始出水 | 开阀时刻（`opened_at`） |
| 这一段停止出水 | 关阀时刻（`closed_at`） |
| 这一次占用结束 | 释放时刻（`ended_at`） |
| 最后一次确认还占着 | 最后确认时刻（`last_seen_at`） |
| 出水累计的时长 | 淋浴时长（设备累计 `bath_time_s`／段之和 `flow_s`，两种来源） |
| 整场占用 | 分配时长（`释放时刻 − 分配时刻`） |
| 入门后到首次开阀 | 等待时长 |
| 我们没看见的那段时间 | 盲区（`observed_span = 'gap'`，长度＝`释放时刻 − 最后确认时刻`） |
| 起点怎么来的 | 起点来源（`assigned_source`） |
| 我们看没看见 | 观测连续性（`observed_span`） |
| 段长证据强度 | 段长来源（`source`） |
| 段记全没有 | 段完整性（`segments_complete`） |
| `free` | 空闲 |
| `selected` | 已选中 |
| `waiting` | 等待开阀 |
| `bathing` | 淋浴中 |
| `paused` | 已暂停 |
| `repair` | 维修中 |
| `disabled` | 已禁用 |
| 占用态集合 | 占用（＝等待开阀／淋浴中／已暂停） |
| 可分配态集合 | 可分配（＝空闲／已选中） |
| 浴室 App 把喷头那一行清零、会话结束 | 释放 |
| 走支付／挂账流程 | 结算（`session.settle`） |
| 停水这个物理动作 | 关阀 |
| 服务器后台按配置自动跑的功能 | 后台任务（预约续期／会话续期／自动结算／延长服务时间，配置在配置页的「服务端业务」页签） |
| 服务端判断偏差并主动把设备钟写准的功能 | 自动校时（`time_sync_enabled`；手动的那一下叫「校正时间」，网页的显示时刻对齐叫「时钟对齐」） |
| 一次上报 | 帧（`door_snapshot`） |
| 我们把命令发给设备 | 下发 |
| 设备把收到的命令跑起来 | 执行（与「下发」相对：下发在我们这一侧，执行在设备那一侧） |
| 当下的钟差 | 偏差（`clock_skew_s`） |
| 钟自然走偏的速率 | 漂移 |
| 浴室 App 读的那份免收费人员名单 | 免费名单（`freelist`） |
| 控制出水的板 | 水控板 |
| 喷头上的按钮 | 电磁阀 |
| 板上允许出水的位 | 授权位（`0x01`） |
| 现场电磁阀按钮的锁存位 | 按钮位（`0x02`） |
| 实际出水的位 | 出水位（`0x04`） |
| 置授权位 | 授权出水（`water.open`） |
| 清授权位与出水位 | 断水（`water.close`） |
| 板累计的授权时间 | 水控板授权计时（`bath_s`） |
| 板累计的出水时间 | 水控板淋浴时长（`allopen_s`） |

## 弃用词

| 弃用词 | 改用 |
|---|---|
| 会话维护 | 后台任务（那三个功能在服务器上按配置自动跑，不叫维护） |
| 刷卡 | 分配（这台设备无卡，`card_no` 实测恒为 0） |
| 进门 | 分配 |
| 入门 | 分配（指时刻时写「分配时刻」，指喷头时写「喷头」） |
| 已入门 | 等待开阀 |
| 缺口 | 盲区 |
| 断层 | 盲区 |
| 断链 | 盲区（指一段时间时）／断连（指连接时） |
| 钟差 | 偏差 |
| 采集端 | NTU Shower（程序）／设备（那台机器） |
| 场次 | 会话 |
| 阀门 | 喷头（「阀门」是浴室 App 内部的水控件） |
| 开水 | 开阀 |
| 在洗 | 占用（状态）／淋浴中（那一段） |
| 发命令 | 下发 |
| 出水时长 | 淋浴时长 |
| 占用时长 | 分配时长 |
| 使用中 | 淋浴中 |
| 快照 | 帧（指一次上报时）／备份（指数据库或配置的存档时，见 RUNBOOK） |
| 终端 | 设备（指那台机器时）；指 shell 时保留「终端」 |
| 代理 | NTU Shower（指我们的程序时）；指 nginx 时保留「代理」 |
| 登录 | 分配（指浴室 App 提交凭证那一刻）／身份（指认证后的主体） |
| 开机校时 | 自动校时 |
| 实时校时 | 自动校时 |
| 时间同步 | 自动校时（指设备钟对齐服务端的功能）／时钟对齐（指网页显示时刻的对齐） |
| 物理开关 | 电磁阀 |
| 同步位 | 按钮位 |
| 被动同步 | 按钮位 |
| 只登记 | 授权出水（置授权位） |
| 登记占用 | 授权出水（不建会话） |
| 已登记占用 | 已授权出水 |
| 开阀位 | 授权位（水控板） |
| 电磁阀按钮位 | 按钮位 |
