# 0001. 全新项目替代旧系统

* 状态：accepted
* 日期：2026-09-29

## 背景与问题

旧系统 ntu-remote-shower 带病：多 worker 状态陈旧、常量多份拷贝、God class。设备现网只能经旧系统触达。

## 考虑过的选项

* 在旧代码上重构
* 全新立项替代，旧系统并行运行至退役

## 决策结果

全新立项。旧系统不动，新系统验证一个功能替代一个。

### 正面后果

* 无历史包袱，可按行业标准打地基

### 负面后果

* 开发期两套系统并行，触达设备需经旧通道
