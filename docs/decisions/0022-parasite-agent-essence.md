# 0022. 项目本质定稿：寄生代理三件主功能

* 状态：accepted
* 日期：2026-09-30

## 背景与问题

浴室 App 无导出组件、uiautomator 永不空闲、自身会崩溃。

## 考虑过的选项

* 替代浴室 App
* 寄生代理：读状态采集、操作 A11y 自动化、活自生命周期

## 决策结果

定性为寄生代理，三件主功能为地基，其余全部是扩展功能。

### 正面后果

* 方向清晰，杜绝功能蔓延

### 负面后果

* 与第三方 App 版本强耦合
